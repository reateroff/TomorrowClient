# TomorrowClient

Минималистичный VPN-клиент для Windows на базе двух ядер — **sing-box** (по
умолчанию) и **xray-core**. Импорт серверов по share-ссылкам, живой счётчик
трафика, тёмный интерфейс. Собран на Wails (Go + React + TypeScript + Tailwind).

## Возможности

- Импорт профилей по ссылкам `vless://`, `vmess://`, `trojan://`, `ss://`
- Подписки (subscription URL): загрузка списка серверов и обновление по кнопке
- Два ядра на выбор: sing-box (нативный TUN + `auto_route`) и xray + tun2socks
- Маршрутизация: по правилам (локальная сеть напрямую) или глобально
- Живая статистика скорости и объёма трафика прямо со счётчиков WinTun-адаптера
- Кастомный DNS, автозапуск соединения
- Frameless окно с собственным тёмным title bar
- Экран «О приложении» в настройках (версия, копирайт, стек)

## Архитектура

```
main.go              — точка входа Wails, окно, биндинги
app.go               — API для фронтенда (профили, настройки, соединение)
internal/model       — общие типы (Profile, AppSettings, Status)
internal/store       — персист профилей и настроек (JSON в %AppData%)
internal/link        — парсер share-ссылок
internal/sub         — загрузчик подписок (base64/plain список ссылок)
internal/singbox     — генератор конфига sing-box
internal/xray        — генератор конфига xray
internal/vpn         — движок: запуск ядер, маршруты, счётчики трафика
frontend/src         — React UI (Tailwind v4, lucide-react)
```

Оба ядра создают WinTun-адаптер с именем `TomorrowTun`; счётчик трафика читает
его байты через `iphlpapi.GetIfTable2`, поэтому статистика единая для обоих
ядер.

## Требования для запуска

Приложение запускает внешние бинарники, лежащие рядом с exe. Их надо скачать
один раз (в git они не хранятся):

```bash
bash scripts/fetch-cores.sh
```

Скрипт кладёт в `build/bin/`:

- `sing-box.exe`
- `xray.exe`
- `tun2socks.exe`

`wintun.dll` также должен лежать рядом с exe (уже в `build/bin` после сборки).

> Приложению нужны права администратора — оно создаёт сетевой адаптер и
> правит таблицу маршрутизации. Это зафиксировано в манифесте
> (`requireAdministrator`).

## Разработка

```bash
wails dev          # запуск в режиме разработки
wails build        # production-сборка в build/bin/
```

Только фронтенд:

```bash
cd frontend
npm install
npm run build
```

## Безопасность

Клиент направляет весь системный трафик в туннель. При режиме «по правилам»
адреса локальной сети (RFC1918, loopback, link-local) идут напрямую в обход
VPN. Трафик до самого прокси-сервера пинится маршрутом через физический шлюз,
чтобы туннель не заворачивал собственные пакеты.
